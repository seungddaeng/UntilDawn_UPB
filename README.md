# UntilDawn_UPB

Proyecto desarrollado en **Unity** para la materia **Entornos Virtuales Multimedios**. El objetivo es construir una experiencia interactiva en primera persona con mecánicas de exploración, sigilo e interacción con NPCs, inspirada en una narrativa de suspenso/terror.

---

## 🎮 Descripción General

**UntilDawn_UPB** es un videojuego donde el jugador debe explorar el Campus de la Universidad Privada Boliviana, interactuar con objetos clave (llaves, linterna, baterías), y evitar o reaccionar ante NPCs con comportamientos autónomos.

El proyecto enfatiza:

* Lógica de gameplay en Unity (C#)
* Interacción jugador–entorno
* IA básica de NPCs
* Control de iluminación y atmósfera
* Flujo de estados del juego (progreso / victoria)
